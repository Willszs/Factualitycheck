# AI Factuality Comparison & Question Generator Tool (AI 测评助手与真实性对比工具)

一个极简本地 Python 桌面应用，集成了：
1. **测试问题设计与双向交互**：桌面输入对话主题 ➡️ 手机 Telegram 交互设定轮数 ➡️ 自动生成高难度事实性考察问题，并支持手机端内嵌按钮【换一个提问】和【获取下一轮】。
2. **多轮对话事实性对比评估**：多轮对话场景下模型 A 与 模型 B 的事实性（Factuality）对比评估，结果纯英文直接推送手机。

---

## 全闭环使用流程

```
[1. 桌面输入主题] ➡️ [2. 手机 Telegram 回复轮数] ➡️ [3. 手机接收高难度问题 & 交互换题]
                                                               ⬇️
[5. 手机接收英文对比评估报告] ⬅️ [4. 粘贴两模型对话并点击发送到手机]
```

### 1. 设计测评问题（全新功能）
- 在软件顶部 **【对话主题】** 输入您想考察的领域（如“量子计算与纠缠”、“古罗马政治体系”）；
- 点击 **【发起主题】**（或直接回车）；
- 手机 Telegram 会收到提示：“请问这段对话大概持续多久/需要几轮？”；
- 在手机上直接回复（例如 `5轮`、`10分钟` 或 `3轮对比`）；
- Bot 立即在 Telegram 推送**第 1 轮高精度事实性测试问题**，并附带两个内嵌按钮：
  - **`[🔄 换一个提问内容]`**：点击后通过 AI 从全新切入点重新生成该轮问题。
  - **`[➡️ 确认，获取下一轮]`**：问完当前轮后，点击继续获取下一轮递进深入的问题。

### 2. 对比评估模型回答
- 拿着问题分别在两个 AI 模型（模型 A 与 模型 B）中完成对话；
- 将两段带轮数的对话记录分别粘贴到桌面软件的 **【粘贴1】** 和 **【粘贴2】**；
- 点击底部的 **【发送到手机】**（或按 `Cmd + Enter`）；
- 输入框**毫秒级清空**，后台异步完成事实性审核；
- 手机 Telegram 收到完整的纯英文对比报告：
  - `The Verdict`（整体评价与对比）
  - `Model A's Flaws`（错误轮数 Round #、错误点、真实 Ground Truth，无错则标注 Flawless）
  - `Model B's Flaws`（错误轮数 Round #、错误点、真实 Ground Truth，无错则标注 Flawless）
